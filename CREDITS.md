# Credits

Every asset, library and data source used by Lone Traveler, with where it came
from and its terms. The in-game Credits screen is built from
`assets/manifest.json` (from M1 on); this file is the human-readable record.

Lone Traveler is a non-commercial, open-source project. It is not affiliated
with or endorsed by NASA. NASA imagery is used under NASA's media usage
guidelines; no NASA insignia or logos are used.
